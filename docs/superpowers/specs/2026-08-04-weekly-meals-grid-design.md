# 주별 급식 가독성 개선 설계

## 목표

주별 급식을 데스크톱에서 월요일부터 금요일까지 한눈에 비교하고, 좁은 화면에서는 편하게 읽을 수 있게 한다.

## 화면 구성

- 데스크톱에서는 월~금 5개 요일을 같은 너비의 열로 배치한다.
- 각 요일 열은 날짜 제목 아래에 해당 급식 정보를 세로로 쌓는다.
- 급식이 없는 날도 같은 카드 구조 안에 빈 상태를 표시한다.
- 모바일에서는 5열을 강제로 축소하지 않고 기존처럼 요일별 세로 카드로 전환한다.

## 기간 제어

- 주별·월별 기간 제어의 가운데 현재 기간 버튼은 초록 배경을 유지한다.
- 버튼 안의 기간 글자는 흰색으로 표시해 배경과 충분한 대비를 만든다.
- 이전·다음 주/달, 이번 주/달로 돌아가기와 데이터 조회 방식은 변경하지 않는다.

## 검증

- 스타일 테스트로 데스크톱 5열, 모바일 1열 전환, 현재 기간 버튼의 흰색 글자를 확인한다.
- 전체 자동화 테스트를 실행한다.
