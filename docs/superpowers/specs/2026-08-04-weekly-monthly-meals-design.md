# 주별·월별 급식 탐색 설계

## 목적

급식 탭을 한 날짜의 식단을 보는 화면에서, 한 주의 식단을 비교하고 월별로 날짜를 찾아보는 화면으로 바꾼다.

## 주별 탭

- 기존 `날짜별` 탭을 `주별`로 바꾸고 기본 탭으로 사용한다.
- 월요일부터 금요일까지의 급식을 날짜 순서대로 세로 카드로 표시한다.
- 각 날짜에 급식이 없으면 `등록된 급식 정보가 없어요` 상태를 해당 날짜 카드에 표시한다.
- 상단 이동은 `이전 주`, 가운데 기간 버튼, `다음 주`로 구성한다.
- 가운데 버튼에는 `2026년 8월 3일 ~ 8월 7일`을 표시하며 누르면 이번 주로 돌아간다.

## 월별 탭

- 기존 `달력` 탭을 `월별`로 바꾼다.
- 월 달력과 선택 날짜의 급식 상세를 유지한다.
- 상단 이동은 `이전 달`, 가운데 월 버튼, `다음 달`로 구성한다.
- 가운데 버튼에는 `2026년 8월`을 표시하며 누르면 이번 달로 돌아간다.

## 공통 원칙

- 주별과 월별은 같은 선택 날짜를 기준으로 전환한다.
- 상단 이동 또는 기간 버튼을 누르면 해당 월의 급식 데이터를 다시 조회한다.
- 기존 알레르기 메뉴 강조는 주별 카드와 월별 상세에 그대로 적용한다.
- 모바일에서는 가운데 기간 버튼이 줄어들 수 있으나, 이전·다음 이동 버튼과 겹치지 않는다.
