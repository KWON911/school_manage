# 급식 알레르기 메뉴 강조 설계

## 목적

사용자가 내 설정에 등록한 알레르기 번호가 식단의 NEIS 표기와 일치할 때, 해당 음식만 명확하게 구분한다.

## 화면 원칙

- 메뉴 단위로만 연한 주황 배경과 테두리를 적용한다.
- 색만으로 구분하지 않고 경고 아이콘과 `알레르기 N번 포함` 문구를 함께 제공한다.
- 일치하지 않는 메뉴는 기존 식단 표현을 유지한다.
- 홈의 오늘 급식과 급식 상세 화면(날짜별·달력의 선택 날짜)에 같은 표현을 사용한다.
- 여러 번호가 일치하면 설정한 번호 순서대로 모두 표시한다.
- 알레르기 설정이 없거나 해당 번호가 없는 메뉴에는 강조와 경고 문구를 렌더링하지 않는다.

## 데이터와 판정

기존 `mealMatchesAllergies(row, allergies)`의 정확한 번호 비교 규칙을 음식 문자열에도 적용한다. 음식 문자열의 괄호 안 번호(예: `계란찜(1.)`)와 사용자 설정 번호가 완전히 같은 경우만 일치로 처리하며, 부분 문자열 비교는 사용하지 않는다.

## 접근성

경고 메뉴는 아이콘과 텍스트 설명을 모두 포함한다. 강조 정보는 메뉴 항목에 포함되어 스크린 리더에서도 메뉴명과 함께 읽힌다.
