# 홈 카드 순차 표시 설계

## 목표

홈 화면에서 시간표와 식단을 일정·개인 캘린더의 응답과 분리해 먼저 표시한다.

## 동작

- 홈 진입 시 시간표, 식단, 학교 일정, 개인 캘린더 요청을 동시에 시작한다.
- 각 요청이 끝나는 즉시 해당 카드만 실제 내용으로 교체한다.
- 아직 끝나지 않은 카드는 카드 안에서 로딩 상태를 유지한다.
- 일정이나 캘린더가 느려도 시간표와 식단은 기다리지 않는다.
- 날짜 이동 및 다시 시도는 동일한 독립 처리 방식을 사용한다.

## 범위

- NEIS, Google Calendar 요청 방식과 캐시 정책은 변경하지 않는다.
- 카드 구성·날짜 이동·알레르기 강조·오류 안내는 유지한다.

## 검증

- 일정 요청을 의도적으로 지연시킨 테스트에서 시간표와 식단 카드가 먼저 보이는지 확인한다.
- 전체 테스트를 실행한다.
