# 시간표 탭 화이트 카드 UI 디자인

## 목적

시간표 탭의 주간 표에서 초록색 과목 칸을 제거해 요일, 교시, 과목을 쉽게 구분한다. 홈과 급식·일정 화면에서 이미 사용하는 흰색 카드와 얇은 테두리의 시각 언어를 따른다.

## 범위

- 데스크톱 주간 시간표의 요일 헤더, 교시 열, 과목 칸
- 모바일 요일별 시간표 카드와 교시별 행
- 데이터 조회, 주간 이동, 현재 요일 판별 및 접근성 구조는 변경하지 않는다.

## 디자인

- 과목 칸은 흰색 배경과 연한 중립 테두리를 사용한다. 과목명은 현재처럼 가운데 정렬한다.
- 요일 헤더와 교시 열은 배경색 블록 대신 진한 텍스트와 표의 간격으로 구분한다.
- 오늘 요일의 헤더와 과목 칸은 기존 골드 포인트의 매우 옅은 배경 및 테두리로만 강조한다. 다른 요일과의 대비는 유지한다.
- 모바일의 `weekday-card`, `period-list li`도 같은 흰색, 연한 테두리, 둥근 모서리를 적용한다.
- 기존 CSS 변수(딥그린 텍스트, 골드 포인트, 카드 테두리)를 재사용하고 새 색 체계는 만들지 않는다.

## 검증

- 시간표 마크업과 기존 주간·모바일 전환 테스트가 유지된다.
- CSS 테스트에 초록색 반투명 배경 제거와 흰색 카드·테두리·오늘 강조 규칙을 추가한다.
- 전체 테스트와 `git diff --check`를 실행한다.
