# 시간표·급식 탭 시각 표현 통일 설계

## 목표

홈 화면에 적용한 과목명 가운데 정렬과 급식 메뉴 일러스트를 시간표·급식 탭에도 적용해 화면 간 표현을 일관되게 한다.

## 범위

- 시간표 탭의 주간 표와 모바일 주간 카드에 표시되는 과목명을 가운데 정렬한다.
- 급식 탭의 일별·주간·월간 상세 메뉴에 음식 유형 일러스트를 표시한다.
- 홈 대시보드의 현재 표현, 시간표/급식 데이터 요청, 알레르기 안내 및 날짜 전환 동작은 유지한다.
- 홈 화면의 전체 보기 버튼 위치 변경은 탭에는 적용하지 않는다. 탭은 이미 전체 화면이므로 동일한 이동 액션이 없다.

## 설계

`modules.mjs`의 시간표 행 마크업에 탭 전용 과목명 클래스를 부여한다. 데스크톱 주간 표와 모바일 카드가 같은 `period-list`를 사용하므로, 과목명 요소에 `text-align: center`를 적용해 두 레이아웃에 같은 결과를 만든다.

급식 메뉴는 홈 대시보드와 동일한 유형 판별 순서(밥, 국/찌개, 고기, 생선, 계란, 김치, 과일, 채소, 기타)를 사용한다. 탭 렌더러에 메뉴 일러스트 마크업을 추가하고, 기존 `meal-item` 스타일 훅을 재사용한다. 아이콘은 장식 처리(`aria-hidden="true"`)하고 메뉴명과 알레르기 경고는 기존 구조를 보존한다.

홈과 탭의 음식 유형 판별이 두 곳에 존재하게 되므로, 동일한 키워드와 SVG를 한 곳의 공용 함수로 모은다. 홈과 탭은 그 공용 함수를 사용해 같은 메뉴가 같은 일러스트를 표시하도록 한다.

## 접근성 및 오류 처리

- 메뉴 텍스트는 기존 HTML escape 경계를 유지한다.
- 알레르기 경고 텍스트 및 아이콘은 그대로 유지한다.
- 음식 일러스트 SVG는 보조기술에 중복 노출하지 않는다.
- 데이터 없음, 네트워크 오류, 서버 오류 상태는 기존 메시지와 액션을 유지한다.

## 검증

- 시간표 모듈에서 과목명 가운데 정렬 훅이 렌더링되는지 확인한다.
- 급식 모듈의 일반 메뉴와 알레르기 메뉴에서 일러스트 및 메뉴명/경고가 함께 렌더링되는지 확인한다.
- 홈 대시보드도 기존 일러스트 렌더링을 유지하는지 확인한다.
- 전체 `npm test`를 실행한다.
