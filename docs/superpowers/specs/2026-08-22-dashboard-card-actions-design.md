# 홈 대시보드 카드 액션 재배치 설계

## 목표

홈 화면의 `시간표 전체 보기`, `급식 자세히 보기`, `일정 전체 보기` 버튼이 카드 하단의 전체 너비를 차지하지 않도록 각 카드 제목 오른쪽의 컴팩트한 텍스트 액션으로 이동한다.

## 범위

- 홈 대시보드의 시간표·급식·일정 카드만 수정한다.
- 액션의 의미와 기존 `data-view` 동작은 유지한다.
- 로딩 상태와 오류 상태의 `다시 시도` 액션은 기존 동작을 유지한다.
- 상세 시간표·급식·일정 화면과 전역 하단 내비게이션은 변경하지 않는다.

## 설계

대시보드 카드 헤더를 제목 영역과 액션 영역의 2열 구조로 만든다. 왼쪽에는 기존 eyebrow와 제목을 유지하고, 오른쪽에는 해당 카드의 보조 액션을 배치한다. 액션은 전체 너비 버튼 대신 투명 배경의 텍스트 링크형 버튼으로 표시하며, `min-height: 44px`를 유지해 터치 접근성을 보장한다.

정상 데이터가 표시되는 카드에서만 전체 보기 액션을 헤더에 렌더링한다. 데이터 로딩 중에는 액션을 표시하지 않고, 오류 상태에서는 기존 오류 설명 아래의 `다시 시도` 액션을 유지한다. 일정 카드도 시간표·급식과 동일한 헤더 액션 패턴을 사용한다.

데스크톱에서는 제목과 액션을 같은 행에 배치하고, 모바일에서는 카드 폭이 좁아질 경우 헤더가 자연스럽게 줄바꿈되도록 한다. 액션이 제목과 겹치거나 잘리지 않도록 `min-width: 0`, `flex-wrap`, 적절한 `white-space` 규칙을 사용한다.

## 접근성 및 오류 처리

- 기존 버튼 요소와 키보드 포커스 스타일을 유지한다.
- 액션 문구는 현재 문구를 유지해 동작을 명확히 전달한다.
- `다시 시도`는 카드 본문에 남겨 네트워크·서버 오류를 복구할 수 있게 한다.
- 정상 데이터가 없는 경우 기존 상태 메시지와 설정 이동 액션을 유지한다.

## 검증

- 정상 시간표·급식·일정 카드에서 액션이 카드 헤더에 렌더링되고 하단에는 렌더링되지 않는지 확인한다.
- 로딩 및 오류 상태에서 액션 동작이 바뀌지 않는지 확인한다.
- 모바일용 CSS 규칙이 존재하고 버튼의 최소 터치 높이 44px를 유지하는지 확인한다.
- 전체 `npm test`를 실행한다.
