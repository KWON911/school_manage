# 홈 대시보드 정렬 및 급식 일러스트 설계

## 목표

홈 화면의 시간표 과목명을 가운데 정렬하고, 급식 메뉴 옆에 메뉴 유형에 맞는 작은 일러스트를 표시한다.

## 범위

- 홈 대시보드의 시간표 미리보기만 수정한다.
- 홈 대시보드의 급식 미리보기만 수정한다.
- 상세 시간표·급식 모듈은 기존 동작을 유지한다.
- 외부 이미지 URL, 네트워크 요청, 새 런타임 의존성은 추가하지 않는다.

## 설계

시간표 행의 과목명 `<strong>`에 전용 클래스를 부여하고, 행 안에서 과목명이 가운데 정렬되도록 CSS를 조정한다. 교시와 상태 정보는 기존 위치와 의미를 유지한다.

급식 메뉴명에서 알레르기 표기 괄호를 제외한 텍스트를 키워드로 검사한다. 밥·국/찌개·고기·생선·채소·계란·김치·과일 순서로 대표 유형을 선택하고, 일치하지 않으면 식판 일러스트를 사용한다. 일러스트는 작은 인라인 SVG로 렌더링하며 `aria-hidden="true"`로 장식 처리한다. 메뉴 텍스트와 알레르기 경고는 현재와 동일하게 escape 및 렌더링한다.

## 오류 및 접근성

- 빈 메뉴, 알 수 없는 메뉴명, 네트워크 오류에서는 기존 상태 메시지를 유지한다.
- 메뉴명에 HTML이 포함되어도 기존 `escapeHtml` 경계를 유지한다.
- SVG는 스크린리더에 중복 노출되지 않는다.
- 색상만으로 메뉴 유형을 구분하지 않는다.

## 검증

- 홈 대시보드 렌더링 테스트에서 과목명 클래스와 가운데 정렬용 스타일 훅을 확인한다.
- 급식 테스트에서 대표 키워드 메뉴가 일러스트를 포함하고, 알레르기 경고가 계속 표시되는지 확인한다.
- 전체 `npm test`를 실행한다.
